# 🌦️ MLOps Project — Weather Prediction (Random Forest)

## 📌 Description
Ce projet illustre un workflow complet de Machine Learning avec DVC et GitHub Actions.
Les étapes incluent :
- Prétraitement des données
- Entraînement du modèle
- Tuning automatique
- Suivi de métriques via CML

## ⚙️ Structure
- `preprocess_dataset.py` : nettoyage et encodage des données
- `train.py` : entraînement du modèle
- `hp_tuning.py` : recherche des hyperparamètres
- `.github/workflows/` : workflows CI/CD
- `dvc.yaml` : pipeline DVC complet
